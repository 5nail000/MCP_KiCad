# Isolated DC-DC module 3–36 V → 5 V / 5 W (XH2.54)

Безымянный изолированный понижающий модуль (листинг Ozon). В официальных библиотеках KiCad **нет** точного part number — на схеме модуль представлен своими двумя разъёмами XH2.54.

Ссылка продавца (не datasheet производителя):

https://ozon.ru/t/NsOjony

## Заявленные параметры (с карточки / шелкографии)

- Тип: изолированный DC-DC, понижающий
- Vin: 3–36 V DC
- Vout: фиксированные 5 V DC
- Мощность: 5 W (≈ 1 A при 5 V — ориентир, не AMR)
- Изоляция: вход и выход гальванически развязаны
- Разъёмы: 2× XH2.54-2P

## Pinout (шелкография модуля)

| Сторона | Метка   | Назначение                         |
|---------|---------|------------------------------------|
| Вход    | Vin+    | + питания (3–36 V)                 |
| Вход    | Gin-    | − входа (первичная «земля»)        |
| Выход   | Vout+   | +5 V                               |
| Выход   | Gout-   | − выхода (изолированная «земля»)   |

**Gin- и Gout- нельзя соединять** — иначе теряется изоляция.

## Как смоделировано в `projects/oxy/oxy`

| Ref | Символ KiCad | Роль |
|-----|--------------|------|
| J1 | `Connector_Generic:Conn_01x02` | Вход XH2.54: pin1=Vin+, pin2=Gin- |
| J2 | `Connector_Generic:Conn_01x02` | Выход XH2.54: pin1=Vout+, pin2=Gout- |
| F1 | `Device:Fuse` | Предохранитель на входе (пример 2 A) |
| R1/D1 | `Device:R` / `Device:LED` | Индикатор +5 V на вторичной стороне |

Цепи: `+12V` → F1 → J1.1 (Vin+); J1.2 (Gin-) → `GND`; J2.1 (Vout+) → `+5V` → R1 → D1 → `GNDA`; J2.2 (Gout-) → `GNDA`.

Земли разделены: `power:GND` (первичная) и `power:GNDA` (вторичная). ERC: 0 нарушений.

Footprint разъёмов: `Connector_JST:JST_XH_B2B-XH-A_1x02_P2.50mm_Vertical` (шаг 2.50 мм ≈ XH2.54).

## PCB (`projects/oxy/oxy/oxy.kicad_pcb`)

Тестовая плата-адаптер 55×30 мм (smoke, не под Gerber): F1, J1/J2 (XH2.54), R1/D1, раздельные GND/GNDA. Пересборка:

```powershell
& "C:\Program Files\KiCad\10.0\bin\python.exe" scripts\build_oxy_pcb.py
uv run kicad-ai validate projects\oxy\oxy
```

## Что проверить до производства

- Реальный Vin в системе (пример на схеме: 12 V; питание на F1.1 / «12V IN»).
- Ток нагрузки ≤ заявленных 5 W / 5 V.
- Не замыкать GND и GNDA на плате и в монтаже.
- Производитель/AMR/изоляция (кВ) — только из реального datasheet модуля, не из названия на Ozon.
